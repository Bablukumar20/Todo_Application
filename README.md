# Dynamic To-Do Application

A responsive JavaScript task management application built for **Task 3 (Medium) – Dynamic To-Do Application**.

## Features

- Add tasks
- Delete tasks
- Mark tasks as completed/uncompleted
- Filter by All, Active, and Completed
- Clear completed tasks
- Progress tracking
- Automatic Local Storage persistence
- Responsive design for mobile and desktop
- No backend or database required

## Technologies

- HTML5
- CSS3
- JavaScript (ES6)
- DOM Manipulation
- Event Handling
- Browser Local Storage

## How to Run

### Option 1: VS Code + Live Server

1. Extract/open this folder in VS Code.
2. Install the **Live Server** extension if you do not already have it.
3. Right-click `index.html`.
4. Select **Open with Live Server**.

### Option 2: Direct browser

Double-click `index.html`. The application works without a server.
